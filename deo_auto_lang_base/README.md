# DEO AutoLang Base

В этой папке находятся два отдельных компонента:

- `src/` и `build.gradle.kts` — Kotlin-модуль с доменными типами, общими для KMP-приложения и платформенных клиентов.
- `catalog_backend/` — Django + Jazzmin источник истины о поддерживаемых автомобильных конфигурациях и пакетах прошивок.

В админке база ведёт статусы проверки, точные параметры автомобиля и привязанные firmware packages. Код разделён на `domain/` (правила), `application/` (сценарии и порты), `infrastructure/` (Django ORM) и HTTP/admin адаптеры. Файлы проходят проверку расширения и лимита размера, хранятся в закрытом каталоге; SHA-256 фиксируется при сохранении. Новые конфигурации и прошивки остаются черновиками/на проверке, пока ответственный специалист не подтвердит их.

Внутренний read-only endpoint `/internal/platform/verified-configurations/` доступен платформенному FastAPI по `X-Base-Catalog-Key`. Он не предназначен для сайта. `backend_side/` не обращается к этому сервису.

Для локальной работы создайте отдельное окружение Python, установите `requirements.txt`, выполните миграции и создайте администратора. До production нужно заменить секреты, добавить независимый audit trail, защищённое объектное хранилище, проверку вредоносных файлов и отзываемые версии пакетов.
