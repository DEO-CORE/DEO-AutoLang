# DEO AutoLang Console

The project resource hub is available at `admin.autolang.deo-core.codes`. Its
staff-only page is implemented in the catalog Django application so it can
reuse the catalog's existing user records and authentication backend without
creating a second credentials database.

This directory remains reserved for the future curator and reviewer workflow:
drafting catalog entries, requesting technical review, and publishing only
after approval by a different reviewer. That workflow is not exposed by the
resource hub.
